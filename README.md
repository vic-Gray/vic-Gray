## 01 / PROFILE OVERVIEW

I'm a software engineer from Nigeria focused on backend development, product infrastructure, and open-source software. I like working on the parts of a product that make it dependable: APIs, data models, authentication, integrations, and the rules that govern how information moves through a system.

I build around real problems—from safer student accommodation to financing infrastructure for smallholder farmers. I'm interested in how systems are designed, how they fail, and how they can be made easier to understand and maintain.

> **Build with intention. Design for reality.**
